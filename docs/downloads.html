Downloads

Every build below is free forever and runs entirely on your machine.

Windows

Windows (CUDA) Download NVIDIA GPUs. The fastest path, every shader lit. Windows (Vulkan) Download AMD and Intel GPUs too. If it has drivers, it runs.

macOS

macOS (Metal) Download Apple Silicon only, Intel Macs not supported yet.

Linux

Linux (CUDA) Download NVIDIA rigs, the enthusiast's choice since forever. Linux (Vulkan) Download Anything else that can push triangles.

Windows: SmartScreen may warn on first launch. Click "More info", then "Run anyway".

macOS: Right-click the app and choose "Open" the first time you run it.

Model weights are not bundled. The app starts with a mock model; download weights once per machine from inside the app, then restart.
